# Model Evaluation Report — House Price Prediction

## Dataset

- **Source:** `house_data.csv` — 300 properties, 8 columns
- **Features:** Area, Bedrooms, Bathrooms, Age, Location, Property_Type
- **Target:** Price
- **Missing values:** none
- **Split:** 80% train (240 rows) / 20% test (60 rows), `random_state=42`

## Models Compared

| Model | MAE | RMSE | R² |
|---|---|---|---|
| Linear Regression | 2,188,736 | 2,907,633 | 0.941 |
| Polynomial Regression (degree 2) | ~0 | ~0 | 1.000 |
| Decision Tree (max_depth=5) | 3,171,748 | 4,150,316 | 0.879 |
| **Random Forest** (n_estimators=200) | **1,483,832** | **2,034,472** | **0.971** |

## Best Model

**Random Forest** is the best general-purpose model: lowest error and
highest R² among models that don't assume a specific formula for price.

The **Polynomial Regression** result (R² ≈ 1.0, error ≈ 0) is a separate
finding worth flagging rather than the "winner" to report at face value:
it shows that in this dataset, `Price` was generated by an almost exact
quadratic formula of the input features. That's a property of this
synthetic dataset, not something to expect on real housing data, so it
isn't a fair comparison to the other models trained under normal
assumptions.

## Most Important Features

Both the linear regression coefficients and the Random Forest feature
importances agree on the ranking:

1. **Area** — by far the strongest driver of price
2. **Location** (especially City Center vs. Rural/Suburb)
3. **Bedrooms** / **Bathrooms** — smaller positive effect
4. **Age** — minimal effect on price

## Key Insights

- Larger properties command higher prices, consistently across all models.
- Location carries a real premium — City Center properties are priced
  noticeably higher than similar properties in Rural or Suburb areas.
- Property age has little bearing on price in this dataset.
- Tree-based models (Random Forest) outperform plain linear regression
  because the relationship between features and price is not purely
  linear.
- The near-perfect polynomial fit indicates the data was synthetically
  generated from a formula, which is useful context when interpreting
  how "good" R² = 0.94–0.97 really is here versus on real-world data.
